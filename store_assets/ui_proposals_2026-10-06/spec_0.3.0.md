## 2. 首頁版面 D（單字當主角）
1. 標題列：App 名稱＋☆（不熟悉單字庫）＋⋮ 選單，維持現有功能。
2. 教材切換：一個下拉按鈕「目前教材名稱　切換教材 ▾」，點開列出全部教材（含自訂教材）。取代現在的 chip。長語言單行放不下時名稱可省略號，但選單內要完整顯示。
3. 單字卡（白色浮起卡片，淺色模式有綠色光暈陰影）：
   - 上方：「No. x / 總數」與「第 N 輪 · NN%」一行，下方細進度條（本輪進度）。
   - 中間：英文單字（Nunito ExtraBold，大小依設定），翻譯在下方用主色。長單字／片語自動縮小，最多兩行，不截斷。
   - 下方控制列：「⏮ 上一個」與「下一個 ⏭」是小膠囊文字鍵，「▶ 開始朗讀／❚❚ 暫停」是中型實心膠囊。按鈕要小，視覺重點在單字。
   - 最下一行小字：「☆ 加入不熟悉單字庫」（暖橘）與「↻ 再讀一次」（灰綠）。長語言時可換兩行。
4. 卡片下方：免費版一行「免費版已解鎖 x / 總數」＋「解鎖更多」小按鈕（點開選看廣告 +20 或升級 Premium）；Premium 不顯示這行。
5. 播放設定：維持可展開卡片，收合時顯示摘要（英雙讀・讀2次・0.9x）。
6. 免費版底部橫幅廣告位置不變；Premium 沒有廣告，單字卡區自動變高。
7. 阿拉伯文右到左：整個版面鏡像，上一個在右、下一個在左；英文單字本身維持左到右。

## 3. 新設定（放在「播放設定」展開區）
1. **單字大小**：小／中／大三段，約 40／52／64sp，預設「中」。長字自動縮小的下限依比例調整。
2. **鎖屏大字封面**：開關，預設開。關閉時不產生封面圖，鎖屏維持一般小字卡片（給不想讓旁人看到的人）。
3. **外觀**（放在 ⋮ 選單或播放設定）：跟隨系統（預設）／淺色／深色。
以上三項都要記住（重開 App 仍保留），11 語都要翻譯。

## 4. 深色模式
1. 全 App 所有畫面（首頁、統計、付費牆、新手導覽、匯入教材、關於、意見回饋、語音測試等）都要在深色下可讀，不能有白底黑字殘留或看不見的文字。
2. 狀態列與導覽列圖示顏色跟著切換。
3. 橫幅廣告本身顏色由廣告商決定，不處理。

## 5. 鎖屏／通知列朗讀卡片
1. 開啟「鎖屏大字封面」時，每換一個字產生正方形封面圖（512×512 PNG，#5B8A72 底、白色大字單字＋翻譯、底下小字「App 名稱 n / 總數」），以 artUri（file://）交給 audio_service；只保留最近幾張圖，避免占空間。封面圖不跟深色模式切換。
2. 標題＝單字、副標＝翻譯、專輯＝「App 名稱 (n / 總數)」維持。
3. 按鈕：上一個、播放／暫停、下一個，三顆都放進精簡檢視（androidCompactActionIndices 0,1,2）。
4. 封面圖文字依 App 語言排版：阿拉伯文右到左、泰文字型正確、長字自動縮小。

## 6. 每日提醒
1. 通知帶 App 主色與大圖示。
2. 內文（排程當下的資料）：有上次進度時「上次聽到：bill 帳單」；否則有不熟悉單字時「還有 N 個不熟悉單字」；都沒有時用原本的通用文案。
3. 按鈕「▶ 開始朗讀」：開啟 App 並直接開始巡航。
4. 按鈕「稍後提醒」：1 小時後再提醒一次（只補一次）。
5. 每次開啟 App、每次換字後一段時間內（節流）重新排程，讓內文盡量新。
6. 不活躍提醒（rescheduleInactivityReminder）同樣套用顏色、大圖示與內文規則。

## 7. 字體與授權
- 只內嵌英文單字用的 Nunito ExtraBold（SIL OFL 1.1，可商用），檔案約 100～150 KB；授權檔一起放進 assets 並註冊到 LicenseRegistry。
- 中文與其他語言用手機內建字體，不另外內嵌。
