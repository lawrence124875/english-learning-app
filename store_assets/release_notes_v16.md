# 第十六版（0.1.13+16）Play 版本資訊

<zh-TW>
・修正部分手機（如小米）鎖定畫面與通知列的朗讀卡片沒有暫停／播放／停止按鈕的問題
・修正播放中快速連按上一個／下一個時，偶爾沒有聲音、聲音與畫面單字不同步或單字跳得太快的問題
・修正關閉 App 後，朗讀卡片仍留在鎖定畫面與通知中心的問題
</zh-TW>

<zh-CN>
・修复部分手机（如小米）锁屏与通知栏的朗读卡片没有暂停／播放／停止按钮的问题
・修复播放中快速连按上一个／下一个时，偶尔没有声音、声音与画面单词不同步或单词跳得太快的问题
・修复关闭 App 后，朗读卡片仍留在锁屏与通知栏的问题
</zh-CN>

<ja-JP>
・一部の端末（Xiaomi など）で、ロック画面と通知の再生カードに一時停止／再生／停止ボタンが表示されない問題を修正しました
・再生中に前へ／次へを素早く連打したとき、まれに音が出ない、音声と画面の単語がずれる、単語が速く進みすぎる問題を修正しました
・アプリを閉じた後も、再生カードがロック画面と通知に残る問題を修正しました
</ja-JP>

<ko-KR>

・재생 중 이전/다음을 빠르게 연속으로 누를 때 가끔 소리가 나지 않거나, 소리와 화면의 단어가 맞지 않거나, 단어가 너무 빨리 넘어가던 문제를 수정했습니다
・앱을 닫은 후에도 재생 카드가 잠금 화면과 알림창에 남아 있던 문제를 수정했습니다
</ko-KR>
