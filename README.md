# 智慧聽覺巡航 - 英語背景朗讀

Flutter 英語單字背景朗讀 App（Android）。內建 NGSL 2809、NGSL-Spoken 720、PHRASE List 506、PhaVE List 150。

- 隱私權政策與 `app-ads.txt`：`docs/`（GitHub Pages）。
- 建置：GitHub Actions（`.github/workflows/`），建置產物不公開。
